# Luis Augusto Mariano | Portfolio

Portfolio digital profissional em Next.js para apresentar atuação em Zoho CRM, automação comercial, integrações via API, Deluge, marketing, tecnologia e IA aplicada a operações comerciais.

## Stack

- Next.js com App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Como instalar

```bash
npm install
```

## Como rodar localmente

```bash
npm run dev
```

Depois acesse `http://localhost:3000`.

## Como fazer build

```bash
npm run build
```

Para validar a versão de produção localmente:

```bash
npm run start
```

## Como publicar na Vercel

1. Suba este projeto para um repositório Git.
2. Acesse a Vercel e importe o repositório.
3. Use as configurações padrão para Next.js.
4. Confirme o deploy.

Não há variáveis de ambiente obrigatórias neste portfolio.

## Estrutura principal

- `src/app/page.tsx`: entrada da página inicial.
- `src/app/layout.tsx`: metadados, idioma e fonte.
- `src/app/globals.css`: estilos globais.
- `src/components/portfolio-page.tsx`: seções visuais do portfolio.
- `src/data/portfolio.ts`: dados de projetos, stack, pilares, trajetória e contato.
